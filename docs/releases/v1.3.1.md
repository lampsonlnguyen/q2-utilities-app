# Q2 Utilities v1.3.1

## Release contents

This is a refreshed installation build of the consolidated `main` branch.
The executable includes the system-theme integration from PR #3 and the
World Clock from PR #4. Both features were already present in v1.3.0; this
patch release does **not** claim new theme functionality.

- Inherits Q2 Pod Minimal, Modern, or Classic styling from
  `/mnt/data/config.ini`, including system accent and light/dark mode.
- Keeps Q2-styled list rows and 26-pixel header, themed selection and
  chevrons across the app.
- Includes World Clock (16 cities), Stopwatch, Calendar, To-do and Calculator.
- Preserves the card-app folder name `.utilities-app` and places Utilities
  in the Library on compatible Q2 Pod builds.
- Built and packaged after host tests and cross-compiled MIPS validation.

## Installation

Download `q2-utilities-app-v1.3.1.zip` from this release and extract it
**at the SD card root**. The resulting files must be:

```
.utilities-app/q2app
.utilities-app/q2-utilities-app
```

Replace any existing files in `.utilities-app`. Remove the obsolete
`.utilities` folder only if it is a duplicate old app installation.
Keep `.utilities-app/tasks.tsv` to preserve your tasks. Close and reopen
Utilities to load the current Q2 system theme.

## Theme note

The app reads Q2 Pod's selected appearance, but the app has no separate
theme selector. Change the theme in Q2 Pod's own Settings, then restart
Utilities. The app recalculates Auto Light Mode as the hour changes.
