# Utilities v1.5.0

- Apple Watch-inspired Digital, Analog and Hybrid stopwatch modes; switch with the clickwheel.
- Redesigned timer with rounded duration cards and high-contrast controls.
- Separate Ringtone Editor with decoded waveform, adjustable 5–30 second selection, WAV preview and compressed MP3 export (libmp3lame or libshine when available).
- New 52 px and 40 px library icons and a 96 px theme-tinted Home shortcut pane for Q2 Pod 1.9.6.
- Build packaging and CI validation updated for all three icons.

The release workflow runs host tests, MIPS compilation and ZIP validation before publication. Physical-device rendering, audio encoder availability and playback require hardware validation.
