# Utilities v1.4.0 — Offline Tools and Icon Menus

This release adds eight new Q2-native utilities while retaining the five existing tools and system-theme inheritance. The executable is built for Shanling Q2 / Q2 Pod, not for a desktop operating system.

## New utilities

- **Pomodoro:** Focus/break sessions, adjustable durations and completed-session counter.
- **Metronome:** Visual pulse, 30–300 BPM, 3/4, 4/4 and 6/8 patterns, and tap tempo. **Audio clicks are not yet available** because Q2 Pod does not currently provide a verified shared-audio interface for this standalone card app.
- **Unit Converter:** Length, mass, speed, temperature, storage; offline with swap.
- **Random Generator:** Bounded integers, D6 die and coin toss (not security-grade random).
- **Countdown Timer:** Start, pause, resume, reset to a custom preset; adjust minutes or seconds.
- **Date Calculator:** Days before/after the system date, including leap days.
- **Engineering Calculator:** Ohm's law, resistor divider, ideal battery runtime.
- **Event Counter:** Four independent channels with atomic SD-card persistence.

## Interface

Two new category rows, **Clocks & Timers** and **Tools & Calculators**, follow the existing five Utilities home items. Each app has a dedicated screen. Small 12×12 pixel monochrome **icon-font glyphs** identify all utilities in the home menu and category lists; no additional assets are required. Icons and selection backgrounds inherit the Q2 Pod Minimal, Modern or Classic theme, accents, and light/dark scheme. Use the click wheel and Centre or touchscreen for every action.

## Compatibility and limitations

Timer deadlines use the Q2's monotonic clock while Utilities remains running, and the visual metronome refreshes on beat changes instead of continuously redrawing. Q2 Pod may close idle apps after a short period; enable **Smart Awake** for longer timer sessions. The timers **do not run in the background after the firmware exits the application**.

Event Counter persists to `.utilities-app/counters.tsv`. Existing to-do items remain in `.utilities-app/tasks.tsv`; **do not delete these files during upgrades**.

## Installation

Download `q2-utilities-app-v1.4.0.zip`, then extract it at the SD-card root, replacing the executable but preserving saved data:

```
.utilities-app/q2app
.utilities-app/q2-utilities-app
```

Open **Library → Utilities** on compatible Q2 Pod firmware. Restart Utilities after changing the system theme.

Automated host tests and Q2 MIPS cross-build packaging must pass before GitHub publishes the release. Physical Q2 audio, battery and prolonged suspend/resume tests are not claimed by CI.
