# Q2 Utilities v1.4.0-beta.1

## Release contents

This is a **beta** build for testing the World Clock map picker. It is not
the next stable release; the map UI may still change before v1.4.0.

- World Clock gains a **World map** picker, in the style of Ubuntu's Date
  & Time settings: a tiny colour world map with a line for every hour of
  longitude, a GMT scale (-12 to +12), the pin city's band highlighted,
  and an info panel with the city and country, its abbreviation and UTC
  offset with the local time, and the date with its difference from Los
  Angeles.
- Turn the wheel to move the pin west to east through the 16 cities, or
  tap the map to jump to the nearest city (tapping the GMT scale picks by
  longitude alone). Press Centre, or tap the info panel, to open that
  city's detail view; Return goes back to the list, focused on the pin's
  city.
- The on-screen `< Back` label is gone from every page: the wheel's
  Return key already goes back, so the 26-pixel bar now shows just the
  centred screen title.
- Everything from v1.3.1 is still here: system-theme styling from
  `/mnt/data/config.ini`, World Clock (16 cities), Stopwatch, Calendar,
  To-do and Calculator.
- Built and packaged after host tests and cross-compiled MIPS validation.

## Installation

Download `q2-utilities-app-v1.4.0-beta.1.zip` from this release and extract
it **at the SD card root**. The resulting files must be:

```
.utilities-app/q2app
.utilities-app/q2-utilities-app
```

Replace any existing files in `.utilities-app`. Remove the obsolete
`.utilities` folder only if it is a duplicate old app installation.
Keep `.utilities-app/tasks.tsv` to preserve your tasks. Close and reopen
Utilities to load the current Q2 system theme.
