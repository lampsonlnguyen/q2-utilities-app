# Q2 Utilities v1.4.3

- **Stopwatch:** the elapsed time is now large enough to read at a glance while running or walking: 4x digits in `MM:SS.t`, switching to `H:MM:SS.t` after an hour. Start, Lap and Reset sit in a row beneath it, and the latest four laps show in a 2×2 grid.
- **To-do:** task names can be up to 140 characters (previously 24). Long names end in "..." in the list, wrap in full on the task's options screen, and the editor shows a character count in the title bar.
- **To-do:** task names are typed on the Q2's own T9 keypad, the same layout as Q2 Pod's keyboard and Books: `, abc def DEL / ghi jkl mno ABC / pqrs tuv wxyz 123 / .?! space Done CLR`. Press a key again within 1.2 s to cycle its letters, which show above the keypad. ABC switches case, 123 types digits, and Done saves.

## Installation

Extract `q2-utilities-app-v1.4.3.zip` at the SD card root and replace the existing `.utilities-app/q2app` and `.utilities-app/q2-utilities-app` files. Keep `.utilities-app/tasks.tsv` and `.utilities-app/counters.tsv` to preserve your saved data; existing tasks load unchanged.
