# Q2 Utilities v1.3.2

- Utilities now uses the Wheel Sensitivity set in Q2 Pod’s **System settings → Controls**. At the default 50%, one selection step takes 28 units of wheel travel.
- Reversing the wheel clears partial travel, and scrolling stops at the first or last item.

## Installation

Extract `q2-utilities-app-v1.3.2.zip` at the SD card root, replacing the existing `.utilities-app/q2app` and `.utilities-app/q2-utilities-app` files. Keep `.utilities-app/tasks.tsv` to preserve your tasks.
